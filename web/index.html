The closing Vegas line for each bout these two have already contested, and whether the model called it right.

How to read this. A percentage is the model’s estimate of how often that fighter wins this matchup. The +/− figure is the same number as a fair American moneyline, with no bookmaker margin added — so the two sides always sum to 100%, which a real sportsbook’s never do.

Model odds are priced as of the last event in the dataset. Fighters are frozen at the careers they had then; this is not a live feed.

On held-out fights the model is right about 63% of the time and the closing line about 70%. It does not beat the market and finds no betting edge — when it disagrees with Vegas, Vegas is usually right. Built as a learning project, not a wagering tool.
